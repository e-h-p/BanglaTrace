# Built-in demo library

These five small Bangla TXT sources are bundled for demonstrations. They correspond to the Mixed essay / Original essay sample buttons. Topics: rivers, climate change, AI in education, language movement and digital economy.

A new session receives separate document copies, parsed and checked by the normal application pipeline. Sources are marked built_in in API summaries and reports. No external requests or model downloads happen while loading the library.

Set ENABLE_DEMO_LIBRARY=false in the repository-root .env and restart for an empty reference collection. The demo files and samples are not a research accuracy benchmark.
